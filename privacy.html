隱私權政策 / Privacy Policy

最後更新：2026-11-25 · Last updated: 2026-11-25

誰在使用 / Who uses it

my-expenses 是個人自用的記帳工具，只有作者本人使用，只會連接作者自己的 Google 帳號。

my-expenses is a personal tool used only by its author, and it connects only to the author's own Google account.

存取哪些資料 / What data it accesses

透過 Gmail API 讀取作者信箱裡的銀行對帳單、帳單附件與購物收據信，用來計算每月支出。

Through the Gmail API it reads bank statements, statement attachments and purchase receipts in the author's mailbox to calculate monthly spending.

資料存在哪裡 / Where data is stored

下載的信件與整理後的結果只存在作者自己的電腦上，不會上傳到任何伺服器。

Downloaded mail and the resulting summaries are stored only on the author's own computer and are not uploaded to any server.

分享 / Sharing

不會出售、分享或轉交任何資料給第三方，也不用於廣告。

No data is sold, shared or transferred to any third party, and none is used for advertising.

撤銷存取 / Revoking access

可以隨時在 Google 帳戶的「第三方存取權」 撤銷這個工具的權限。

Access can be revoked at any time from the Google Account third-party access page.
